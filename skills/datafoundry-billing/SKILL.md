# 余额与充值

前置:凭据已就绪。**红线:智能体只建单与查账,扫码付款永远是用户本人。**

## 步骤

**1. 查余额**:`GET $BASE/billing/me -H "X-API-Key: $KEY"` → balance(单位=样本额度)与订单列表。

**2. 列套餐**:`GET $BASE/billing/plans`,把价格与额度报给用户,由用户选。

**3. 建单**(用户选定后):
```bash
curl -s -X POST "$BASE/billing/orders?plan=<starter|pro|...>" -H "X-API-Key: $KEY"
```
响应含订单号与支付信息(pay_url 或 code_url)。**把支付链接原样交给用户**:
"请打开此链接完成支付(支付宝电脑网站支付)";链接含时间戳,过期就重建一张,别让用户付旧单。

**4. 到账核验**:用户说付完后,轮询 `GET /billing/me` 看 balance 增加、对应订单
status=paid。到账即报:"已入账 +N 额度,当前余额 M。"支付回调是幂等的,重复通知不会重复入账。

## 失败分支

- 长时间未到账:先确认用户确实完成支付;是则报订单号请管理员核对支付宝账单,
  **绝不私自补账**(账本只认支付回调这一个写入点)
- 建单 500:计费服务未配置或网关异常,报错误请用户稍后再试
