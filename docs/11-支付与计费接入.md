## 1. TinyShip 组件清单 → 我们的采用决策

| 组件 | TinyShip 用途 | 我们的决策 |
|---|---|---|
| **微信支付 APIv3** | 国内收款 | ✅ 采用,经开源 SDK [wechatpayv3](https://github.com/minibear2021/wechatpayv3)(签名/验签/AES-GCM 解密全封装,Native 下单出 code_url 二维码);`pip install "datafoundry[billing-wechat]"` |
| **支付宝** | 国内收款 | ✅ 采用,开源 `python-alipay-sdk`(RSA2);**实际上线为电脑网站支付 page.pay**(2026-08-14 按已签约能力切换,`ALIPAY_PRODUCT` 可选 page/precreate;当面付因 40004 未签约弃用),`ALIPAY_SANDBOX=1` 走沙箱网关 |
| **Stripe** | 国际收款 | ✅ 采用,**标准库直连**(Checkout Session + 官方 HMAC 回调验签方案),零 SDK 依赖 |
| DodoPayments | 国际 MoR(代扣税) | 🔲 记录备选:出海规模化再评估(MoR 抽成换税务合规) |
| Better-Auth | 登录(微信/手机号/2FA) | 🔲 TypeScript 生态,归**外壳仓库**(gate 后);内核已有的 argon2+JWT+API Key+设备码不动,外壳↔内核走 API Key/OIDC |
| shadcn/ui、Fumadocs、CF Workers | 前端/文档/部署 | 🔲 全归外壳仓库(gate 后) |

**红线复核**:以上采用件全部开源(Apache/MIT)或标准服务 API,无闭源运行时依赖 ✅。

## 2. 架构:账本在内核,收银台在外壳

```mermaid
flowchart LR
    subgraph 外壳[商业外壳(gate 后,TinyShip)]
        UI[收银台/套餐页/二维码展示]
    end
    subgraph 内核[DataFoundry 内核(已实现)]
        O[POST /billing/orders<br/>建单+调网关] --> P[(orders + credit_ledger<br/>额度事实源)]
        W[POST /billing/webhook<br/>验签+幂等入账] --> P
        G[POST /billing/grant<br/>admin 手工上账] --> P
        R[POST /runs<br/>按样本数扣额度,不足 402] --> P
    end
    UI --> O
    微信/支付宝/Stripe -->|支付回调| W
```

设计要点(测试均已覆盖):
- **网关可插拔**:`PaymentProvider` 抽象(下单 + 回调验签解析两个方法);mock 网关全功能可测
- **回调幂等**:`mark_order_paid` 单事务内"pending→paid + 记账",重复回调不重复入账
- **额度模型**:1 额度 = 1 条样本处理;run 创建时校验并扣减,不足返回 402;admin 豁免
- **手工上账通道** `/billing/grant`:对公转账/PoC 合同的 B2B 现实路径,全程审计
- **验签从严**:mock 用 HMAC;Stripe 按官方 `t=,v1=` 方案含时间容差;微信由 SDK 验签解密

## 3. 启用方式

```bash
# 开发/联调(mock 网关)
export DATAFOUNDRY_BILLING_PROVIDER=mock DATAFOUNDRY_BILLING_SECRET=xxx

# Stripe(国际)
export DATAFOUNDRY_BILLING_PROVIDER=stripe STRIPE_API_KEY=sk_... STRIPE_WEBHOOK_SECRET=whsec_...

# 微信支付(国内,需商户号)
pip install "datafoundry[billing-wechat]"
export DATAFOUNDRY_BILLING_PROVIDER=wechatpay WECHATPAY_MCHID=... WECHATPAY_APPID=... \
       WECHATPAY_PRIVATE_KEY=... WECHATPAY_CERT_SERIAL_NO=... WECHATPAY_APIV3_KEY=... \
       WECHATPAY_NOTIFY_URL=https://你的域名/billing/webhook
```

套餐定义在 `billing.py` 的 `PLANS`(入门 99 元/10 万样本、专业 499 元/100 万、PoC 9900 元/1000 万),
定价依据 docs/10 §4 的 Steph Ango 路线与 docs/02 §6 锚点,数字待商业验证(M3-H3)校准。
