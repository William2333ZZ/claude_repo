# 评测集口径 [M1-A1]

## math_zh_v1(中文数学应用题,60 题)

**领域决策**:M1 证伪实验选定**可验证域·数学推理**。理由(docs/04 §2):可验证域的质量可被
机器硬保证,四路对比中"带验证器的漏斗产线 vs 无验证的产线"分化机制最清晰;判分精确匹配,
天然满足"波动 < 2 分"验收。`[产品待确认]`——若产品判断首个垂直应为文档 QA,本评测集降级为
次要指标,另立文档 QA 评测集事项。

**构建方式**:12 个参数化模板 × 5 实例,答案由生成代码计算(构造上零答案错误);
固定种子 20260811,任何机器重跑逐字节一致。覆盖:找零、行程、折扣、平均数、工程合作、
年龄、鸡兔同笼、注水、比例分配、利润率、等差求和、植树。全部整数答案。

**已知局限(如实记录)**:模板生成的题面多样性有限;若训练数据也从同类模板合成,存在
"考训同源"高估风险——四路对比是**组间相对比较**,四组共享同一评测集,相对结论仍成立,
但绝对分数不代表通用数学能力。v2 计划混入人工改写题面对冲。

## 评测协议(违反任何一条,分数不可比)

1. **解码**:temperature=0(贪心),max_tokens=512
2. **prompt 模板**(逐字固定):

   ```
   请解答下面的数学题,一步步思考,最后一行只写「答案: <数字>」。
   题目:{question}
   ```

3. **判分**:优先取「答案:」后的数字;取不到则取输出中最后一个数字;与标准答案数值相等
   (整数化比较)记 1 分,否则 0 分。总分 = 正确数/60×100,四舍五入到 0.1
4. **波动验收**:同一模型同一权重跑两遍,分差必须 < 2 分(贪心解码下应为 0)

